# Japón · aprende y juega

App de estudio para el viaje a Japón (27/06 → 21/07/2026): quiz con mapa real,
lecciones, cronologías, glosario, flashcards, examen con diploma y progreso.

- **Web/PWA**: https://francescvicente-png.github.io/ — instalable con
  "Añadir a pantalla de inicio"; funciona offline gracias a un service worker
  y guarda el progreso en el navegador.
- Un solo archivo `index.html` autocontenido (mapa GeoJSON simplificado +
  ilustraciones Noto Emoji incrustadas). `sw.js` y `manifest.webmanifest`
  añaden el modo app.
